# quantx

A 股日频量化回测与人工实盘系统。

## 设计文档

- [详细设计文档](docs/design.md)：系统架构、数据层、股票池、因子库、组合构建、自研 A 股回放回测、人工实盘执行、风控、对账与归因。

## 范围

- 市场：沪深主板、创业板、科创板（创业板/科创板需开通对应权限）
- 方向：只做多，不融资融券
- 资金：按权益推导持仓数/单票上限，默认低于 15 万元禁止新买，允许经验证卖出；现有持仓保持股数，不每日等权加减
- 回测：2015 年起日线研究；具备 5 分钟和留存 PIT 快照时做生产执行回放，否则按设计完成生产上下文模拟盘验收
- 频率：日频，14:20 账户快照、14:30 输入截止，目标 14:35 发布（最晚 14:40）、14:55 前人工执行，收盘后录入当日成交并完成初步对账，T+1 完成正式对账
- 执行：系统生成调仓单，人工在券商客户端执行，成交结果人工录入；无有效账户快照不交易
- 规则：板块权限/价格笼子/2015+ 规则表；红利税、现金利息、整数分记账
- 风控：T-1 公司行为预调整、BLOCK 分级强制退出、影子组合回撤/恢复、release 冻结
