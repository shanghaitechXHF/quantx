# quantx

A 股日频量化回测与人工实盘系统。

## 设计文档

- [详细设计文档](docs/design.md)：系统架构、数据层、股票池、因子库、组合构建、自研 A 股回放回测、人工实盘执行、风控、对账与归因。

## 范围

- 市场：沪深主板、创业板、科创板
- 方向：只做多，不融资融券
- 资金：按权益推导持仓数/单票上限，默认最低 15 万元
- 回测：2015 年起日线研究 + 近期 5 分钟执行校准；5 分钟数据可选
- 频率：日频，14:20 账户快照、14:30 生成信号，收盘前人工执行，收盘后录入当日成交并完成初步对账，T+1 完成正式对账
- 执行：系统生成调仓单，人工在券商客户端执行，成交结果人工录入；无有效账户快照不交易
